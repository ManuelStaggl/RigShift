# RigShift brand assets

The RigShift source code is licensed under the [MIT License](../../LICENSE). **The RigShift logo, symbol and app
icons are not.** They are © 2026 Manuel Staggl, all rights reserved.

This covers:

- `docs/brand/` – logo files (`*.svg`, `*.png`)
- `src/RigShift.App/Assets/Brand/` – symbol images (`*.png`) and icons (`*.ico`)

The colour tokens in `src/RigShift.App/Assets/Brand/*.xaml` are ordinary source code under MIT.

## What you may do

- Use the unmodified logo to refer to RigShift – in articles, videos, reviews, tutorials, link lists or community posts.
- Show screenshots of the app, including the logo and icons.
- Build and run the official repository as it is.

## What needs a different look

- **Forks and derived apps** must replace the logo, symbol and icons with their own and must not present themselves as
  the official RigShift. The MIT license still lets you reuse all of the code.
- Don't modify the logo or use it for other products, merchandise or anything implying endorsement.

Questions: open an issue.

## Third-party symbols

The profile symbols (Desk, Rig, VR, TV, Stream) are [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons)
by Microsoft, delivered through the WPF-UI symbol font, and remain under their MIT license.
