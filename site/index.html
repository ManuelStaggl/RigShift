Switches by itself

A USB rule on the rig profile: wheelbase and pedals on, rig mode. Off for as long as you choose, desk mode. Or a hotkey, the tray, a Stream Deck button.

Never stuck on a black screen

The whole layout goes to Windows in one step. Sleeping monitors are woken and waited for. No picture? A countdown reverts it – any wheel button keeps it.

The whole evening, one click

A game entry switches the profile, starts SimHub and Crew Chief, puts their windows back, launches the sim from Steam or Epic and cleans up when you quit.

Is it safe?

RigShift is a free hobby project and not code-signed, so Windows shows "Windows protected your PC" the first time: More info → Run anyway. Smart App Control (Windows 11) blocks unsigned apps outright.

The download is about 80 MB because it brings its own .NET runtime. Updates after that are a few MB.

Check it instead of trusting it:

  • All source on GitHub, MIT licensed. The only network request asks GitHub for updates – privacy.
  • Every release links its VirusTotal scan.
  • Every release carries a GitHub build attestation:
    gh attestation verify RigShift-win-Setup.exe -R ManuelStaggl/RigShift
  • SHA256SUMS and an SBOM in every release.
