# Code of conduct

RigShift follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep criticism about code and ideas, not people. Harassment,
insults and personal attacks are not tolerated in issues, pull requests or anywhere else in this project.

Report problems privately via
[**Security → Report a vulnerability**](https://github.com/ManuelStaggl/RigShift/security/advisories/new)
(it reaches the maintainer only) – the maintainer will review it and may remove content or block accounts.
